# Go (Fiber) — Pier starter template

A high-performance HTTP API built with [Fiber](https://gofiber.io).

## Run locally

```bash
go run .
# → http://localhost:8080
```

The server listens on `$PORT` (default `8080`).

## Deploy on Pier

Instantly from the console — **Deploy → From a template** — or from this
directory with the CLI:

```bash
pier create app
```
