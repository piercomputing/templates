# Next.js (Static Export) — Pier starter template

A static site built with [Next.js](https://nextjs.org) (`output: "export"`).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # static output in out/
```

## Deploy on Pier

Instantly from the console — **Deploy → From a template** — or from this
directory with the CLI:

```bash
pier create site
```
