# Rust (Axum) — Pier starter template

A type-safe HTTP API built with [Axum](https://github.com/tokio-rs/axum).

## Run locally

```bash
cargo run
# → http://localhost:8080
```

The server listens on `$PORT` (default `8080`).

## Deploy on Pier

Instantly from the console — **Deploy → From a template** — or from this
directory with the CLI:

```bash
pier create app
```
