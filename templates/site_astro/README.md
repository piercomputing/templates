# Astro — Pier starter template

A content-focused static site built with [Astro](https://astro.build).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build   # static output in dist/
```

## Deploy on Pier

Instantly from the console — **Deploy → From a template** — or from this
directory with the CLI:

```bash
pier create site
```
